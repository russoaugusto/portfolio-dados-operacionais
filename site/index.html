02 SQL

O que o JOIN está contando?

Uma ordem pode ter vários eventos. Ao juntar as tabelas, uma mesma ordem pode aparecer mais de uma vez.

Granularidade de ordens e eventos
OrdemEventosLinhas após JOIN

Método. Conte os eventos por ordem antes de juntar as tabelas. Se o indicador mede ordens, preserve uma linha por ordem.
